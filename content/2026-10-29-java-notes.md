## 오늘의 질문

메서드를 호출할 때 넣는 값과, 실행 후 돌려받는 값은 어떻게 다를까?

## 작은 코드로 확인하기

메서드는 이름을 붙여 다시 사용할 수 있는 코드 묶음입니다. `a`와 `b`는 입력을 받는 **매개변수**, `return`은 결과를 돌려주는 구문입니다.

```java
static int add(int a, int b) {
    return a + b;
}

int result = add(2, 3);
System.out.println(result); // 5
```

## 실행 순서

1. `add(2, 3)`을 호출합니다.
2. `a`에 2, `b`에 3이 전달됩니다.
3. 두 값을 더한 5를 반환합니다.
4. 반환된 값이 `result`에 저장됩니다.

## 헷갈렸던 지점

| 구분 | 의미 |
| --- | --- |
| 매개변수 | 메서드가 입력을 받는 변수 |
| 반환값 | 실행 후 호출한 곳에 돌려주는 값 |
| void | 반환값이 없다는 표시 |
